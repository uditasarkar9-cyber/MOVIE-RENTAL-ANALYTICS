# 🎬 Movie Rental Analytics Dashboard

## 📌 Project Overview
This project analyzes the Sakila DVD Rental database using Power BI to uncover insights related to customer behavior, rental trends, film performance, inventory management, and revenue generation.

The dashboard helps in understanding business performance and supports data-driven decision-making.

---

# 📊 Tools & Technologies Used
- Power BI
- SQL (MySQL)
- Excel
- DAX
- Data Modeling
- Power Query

---

# 📂 Dataset
The project uses the Sakila DVD Rental database which contains:
- Customer information
- Rental transactions
- Film details
- Payment records
- Inventory data
- Staff & store data

---

# 📈 Dashboard Features

## Customer Analytics
- Customer distribution by country
- Top customers by revenue
- Customer segmentation
- Rental behavior analysis

## Sales Analytics
- Monthly revenue trend
- Revenue by category
- Country-wise sales performance
- Rental revenue insights

## Film Analytics
- Top rented films
- Film category analysis
- Rental duration analysis
- Film language distribution

## Inventory & Staff Analytics
- Inventory distribution
- Staff performance analysis
- Store performance tracking
- Rental activity monitoring

---

# 🔗 Key Insights
- Identified high revenue-generating film categories
- Analyzed monthly rental trends
- Tracked customer contribution to revenue
- Compared store and staff performance
- Evaluated rental behavior patterns
